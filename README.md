# 店大人运营知识库

一个面向运营团队的静态知识库页面：把官网帮助、30 分钟新人入门、视频拆解和 AI 提问模板放在一个可搜索的工作台里。

## 页面能力

- 左侧按模块浏览，支持新人训练、全部文档和官网帮助分类。
- 搜索任务、菜单、按钮或关键词，点击结果在右侧展开操作说明。
- 30 分钟入门路径、按任务快速入口、证据标签（官网 / 视频 / 培训 / 推断）。
- 每篇文档可复制一段给 AI 的教练式提问模板。
- 纯静态 HTML/CSS/JS，无数据库、无账号、无密钥，适合 GitHub Pages。

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器打开 <http://127.0.0.1:4173>。

## GitHub Pages

仓库内的 `.github/workflows/pages.yml` 会在推送到 `main` 后部署静态页面。仓库设置里将 Pages 的构建来源设为 **GitHub Actions**，即可获得 Pages 地址。

如果知识库包含内部运营方法，建议使用私有仓库并只邀请运营团队；只有确认可以公开时，才把仓库切换为 public。

## 内容边界

- 26 篇官网帮助以官网文章为主，页面保留来源链接，版本和平台规则仍需以当前客户端核验。
- 视频部分只发布时间轴和动作摘要，不上传原始视频，也不发布本机路径、账号、Cookie、客户资料或密钥。
- “架构”是使用层分析，不代表店大人的内部代码、数据库或 API 实现。

数据快照生成脚本位于 `scripts/build-data.mjs`；页面提交的是已经脱敏的 `content/data.js`，可离线运行。
